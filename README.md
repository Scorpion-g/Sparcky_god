## Fonctionnalités
- 🛡️ **Modération** : warn, kick, ban, timeout, anti-link, anti-badwords, sanction automatique  
- 💰 **Économie** : daily, money, leaderboard  
- 🎮 **Fun & Utiles** : chifumi, rolereact, level, userinfo, embed, delmess  
- 🎟️ **Tickets** : système complet de tickets  
- 📊 **Level System** : suivi du niveau des membres avec RankCard personnalisée  
- ⚙️ **Configuration** : réglages complets via commandes slash
